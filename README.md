# flags
a game to guess flags with pyturtle
🇪🇺 Flag Guessing Game (Python Turtle)

This is a simple Python game built using the Turtle graphics library. The program displays a randomly selected European flag, and the player must guess which country the flag belongs to. The game keeps track of the player’s score and remaining lives, and each flag can only be guessed once.

🎮 How It Works

A random flag is drawn on the screen

The player types the country name in the console

Correct guesses earn points

Incorrect guesses reduce lives

The game ends when lives run out or all flags are guessed
